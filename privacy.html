Tidy Notes는 Windows용 데스크탑 메모 앱입니다. 메모는 사용자의 PC와 사용자 본인의 Google Drive에만 저장됩니다. 개발자는 사용자의 메모나 계정 정보를 받거나 보관하는 서버를 운영하지 않습니다.

Tidy Notes는 사용 통계, 광고 식별자, 오류 보고를 수집하지 않습니다. 앱의 진단 기록(로그)에는 메모 내용과 토큰을 남기지 않습니다.

2. Google Drive 권한

Google 계정을 연결하면 Tidy Notes는 drive.file 권한 하나만 요청합니다. 이 권한으로는 Tidy Notes가 직접 만든 파일만 보고 고칠 수 있습니다. 사용자가 Drive에 올려 둔 다른 파일과 폴더는 볼 수 없습니다.

Tidy Notes가 Drive에서 하는 일은 다음뿐입니다.

  • 내 드라이브에 TidyNotes 폴더를 만들고, 그 안에 메모 한 장당 파일 하나(notes/)와 메모 속 이미지(assets/)를 저장합니다.
  • 다른 PC에서 바뀐 메모 파일을 내려받아 이 PC의 메모에 반영합니다.
  • 연결된 계정의 이메일 주소를 확인합니다.

3. Google 사용자 데이터 사용 원칙

Tidy Notes가 Google API로 받은 정보를 사용하고 다른 앱으로 옮기는 방식은 제한적 사용(Limited Use) 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

  • Google 사용자 데이터는 메모 저장·동기화라는 앱 기능에만 씁니다.
  • 누구에게도 팔거나 넘기지 않으며, 광고에 쓰지 않습니다.
  • 개발자를 포함해 어떤 사람도 사용자의 데이터를 읽지 않습니다.
  • AI·머신러닝 모델 학습에 쓰지 않습니다.

4. 전송과 보안

로그인은 Google의 표준 방식(OAuth 2.0과 PKCE)으로, 사용자의 기본 브라우저에서 이루어집니다. 비밀번호는 Tidy Notes에 입력되지 않습니다. 앱과 Google 사이의 통신은 모두 HTTPS로 암호화됩니다. 로그인 토큰은 Windows 자격 증명 관리자에만 저장하며, 메모 데이터베이스나 설정 파일에는 저장하지 않습니다.

5. 보관과 삭제

  • 연결 끊기: 설정 → Google 계정 → 연결 끊기를 누르면 Google 쪽 권한을 취소하고 PC에 저장된 토큰과 이메일을 지웁니다. 이 PC의 메모는 그대로 남습니다.
  • Google에서 직접 취소: Google 계정 → 서드파티 앱 및 서비스에서 Tidy Notes의 접근 권한을 언제든 취소할 수 있습니다.
  • Drive의 메모 지우기: 내 드라이브의 TidyNotes 폴더를 지우면 됩니다.
  • PC의 메모 지우기: 앱을 제거한 뒤 %APPDATA%\TidyNotes 폴더를 지우면 됩니다.

6. 어린이

Tidy Notes는 업무용 메모 앱이며 만 14세 미만 어린이를 대상으로 하지 않습니다.

7. 바뀌는 경우

이 방침이 바뀌면 이 페이지에 새 시행일과 함께 올립니다. 다루는 정보나 권한이 늘어나는 변경은 앱 안에서도 알립니다.

Summary in English

Tidy Notes is a Windows desktop sticky-notes app. Notes are stored only on the user's PC and in the user's own Google Drive. The developer runs no server that receives or stores user notes or account data.

When the user connects a Google account, the app requests only the drive.file scope, which allows access solely to files the app itself creates (a TidyNotes folder with one JSON file per note and note images). The app reads the account email address to show which account is connected. OAuth tokens and the email address are stored only in the Windows Credential Manager on the user's PC.

Tidy Notes' use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is used only to store and sync the user's notes, is never sold, transferred, used for advertising, read by humans, or used to train AI/ML models.

Users can disconnect in Settings → Google account, revoke access at myaccount.google.com/permissions, and delete the TidyNotes folder from their Drive at any time.
