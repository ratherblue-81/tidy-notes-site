시행일 2026년 11월 18일

Tidy Notes는 Windows용 데스크탑 메모 앱과, 그 메모를 휴대폰 브라우저에서 보는 휴대폰 보기(Pro)로 이루어져 있습니다. 메모는 사용자의 PC와 사용자 본인의 Google Drive에만 저장됩니다.

  • 개발자는 당신의 메모·계정을 받지도, 보지도, 보관하지도 않습니다. 개발자 서버가 없습니다.
  • 앱은 Drive에서 자기가 만든 TidyNotes 폴더 말고는 아무것도 볼 수 없습니다. Google이 권한으로 막아 둡니다.
  • 사용 통계·광고·오류 보고, 아무것도 수집하지 않습니다.

2. Google Drive 권한

Google 계정을 연결하면 Tidy Notes는 Drive 권한으로 drive.file 하나만 요청하고, 로그인한 계정을 확인하는 기본 권한(openid, email)을 함께 요청합니다. 이 권한으로는 Tidy Notes가 직접 만든 파일만 보고 고칠 수 있습니다. 사용자가 Drive에 올려 둔 다른 파일과 폴더는 볼 수 없습니다.

Tidy Notes가 Drive에서 하는 일은 다음뿐입니다.

  • 내 드라이브에 TidyNotes 폴더를 만들고, 그 안에 메모 한 장당 파일 하나(notes/), 메모 속 이미지(assets/), 메모에 첨부한 파일(files/)을 저장합니다.
  • 다른 PC에서 바뀐 메모 파일을 내려받아 이 PC의 메모에 반영합니다.
  • 연결된 계정의 이메일 주소를 확인합니다.

휴대폰 보기(Pro)는 같은 drive.file 권한으로, 휴대폰 브라우저가 Google Drive에 직접 연결합니다. 개발자 서버를 거치지 않습니다. 휴대폰 보기가 하는 일은 다음뿐입니다.

  • TidyNotes 폴더의 메모 파일과 이미지를 읽어 화면에 보여 줍니다. 메모는 브라우저 탭 메모리에만 두고 휴대폰에 저장하지 않습니다.
  • 사용자가 할일을 체크하거나 풀면, 그 메모 파일의 해당 할일 표시만 바꿔 다시 저장합니다.
  • Pro 키가 지금 로그인한 계정용인지 비교하려고 계정 이메일 주소를 확인합니다.

Pro 구독 확인: PC 앱과 휴대폰 보기는 한 달에 한 번쯤, Google이 서명한 신원 증명(ID 토큰, Drive 권한 없음)을 Tidy Notes 라이선스 확인 서버로 보냅니다. 서버는 그 이메일로 Paddle에 구독 상태만 묻고, 구독 중이면 Pro 키를 돌려줍니다. 이메일은 확인하는 그 순간에만 쓰고 저장하지 않으며, 서버는 Drive에 접근할 수 없고 메모를 받지 않습니다.

3. Google 사용자 데이터 사용 원칙

Tidy Notes가 Google API로 받은 정보를 사용하고 다른 앱으로 옮기는 방식은 제한적 사용(Limited Use) 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

  • Google 사용자 데이터는 메모 저장·동기화라는 앱 기능에만 씁니다.
  • 누구에게도 팔거나 넘기지 않으며, 광고에 쓰지 않습니다.
  • 개발자를 포함해 어떤 사람도 사용자의 데이터를 읽지 않습니다.
  • AI·머신러닝 모델 학습에 쓰지 않습니다.

4. 전송과 보안

로그인은 Google의 표준 방식(OAuth 2.0과 PKCE)으로, 사용자의 기본 브라우저에서 이루어집니다. 휴대폰 보기는 Google 로그인 창에서 로그인하며, 받은 접근 토큰은 브라우저 탭 메모리에만 두고 로그아웃하면 Google에 취소를 요청합니다. 비밀번호는 Tidy Notes에 입력되지 않습니다. 앱과 Google 사이의 통신은 모두 HTTPS로 암호화됩니다. 로그인 토큰은 Windows 자격 증명 관리자에만 저장하며, 메모 데이터베이스나 설정 파일에는 저장하지 않습니다.

5. 보관과 삭제

  • 연결 끊기: 설정 → Google 계정 → 연결 끊기를 누르면 Google 쪽 권한을 취소하고 PC에 저장된 토큰과 이메일을 지웁니다. 이 PC의 메모는 그대로 남습니다.
  • Google에서 직접 취소: Google 계정 → 서드파티 앱 및 서비스에서 Tidy Notes의 접근 권한을 언제든 취소할 수 있습니다.
  • Drive의 메모 지우기: 내 드라이브의 TidyNotes 폴더를 지우면 됩니다.
  • PC의 메모 지우기: 앱을 제거한 뒤 %APPDATA%\TidyNotes 폴더를 지우면 됩니다.
  • 휴대폰 보기: 로그아웃하거나 탭을 닫으면 메모와 토큰이 사라집니다. 저장된 Pro 키는 브라우저의 사이트 데이터 지우기로 지울 수 있습니다.

6. 어린이

Tidy Notes는 업무용 메모 앱이며 만 14세 미만 어린이를 대상으로 하지 않습니다.

7. 바뀌는 경우

이 방침이 바뀌면 이 페이지에 새 시행일과 함께 올립니다. 다루는 정보나 권한이 늘어나는 변경은 앱 안에서도 알립니다.

Summary in English

Tidy Notes is a Windows desktop sticky-notes app. Notes are stored only on the user's PC and in the user's own Google Drive. The developer runs no server that receives or stores user notes or account data.

When the user connects a Google account, the app requests only the drive.file scope, which allows access solely to files the app itself creates (a TidyNotes folder with one JSON file per note, note images, and files the user attaches to notes). The app reads the account email address to show which account is connected. OAuth tokens and the email address are stored only in the Windows Credential Manager on the user's PC.

To check for updates, the app reads a version file from GitHub (github.com) about once a day and downloads the installer from there when a new version exists. No notes or account data are sent. Automatic installation can be turned off in Settings → Version.

The mobile view (Pro) runs in the phone's browser and connects directly to the user's Google Drive with the same drive.file scope, without any developer server. It reads the note files to display them (kept in tab memory only, never stored on the phone), writes back only the checked state of a to-do item when the user taps it, and reads the account email to check that the Pro key belongs to the signed-in account.

Pro subscriptions are handled by Paddle (payments, renewals, cancellations, refunds). About once a month the apps send a Google-signed identity token (OpenID, no Drive access) to the Tidy Notes license server, which asks Paddle whether that email has an active subscription and returns a signed Pro key. The email is used only during that check and is not stored; the license server never receives notes and cannot access Drive.

Tidy Notes' use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is used only to store and sync the user's notes, is never sold, transferred, used for advertising, read by humans, or used to train AI/ML models.

Users can disconnect in Settings → Google account, revoke access at myaccount.google.com/permissions, and delete the TidyNotes folder from their Drive at any time.
